# Project notes

Termux MCP is designed as a mobile-first bridge between AI coding agents and an Android Termux environment. The repository deliberately does not contain a personal ngrok token, a personal domain, or a prebuilt ngrok binary. `install.sh` downloads the correct binary for the user's architecture and configures the user's own token locally.

The public URL is generated by the user's ngrok session. Anyone who can use that URL may be able to execute commands as the current Termux user, so the URL must remain private and the bridge should be stopped with `Ctrl+C` when it is not needed.
